# Sprint Notes (2 jours)

## Objectif
Rendre la page `notes` pleinement utilisable pour **étudiants, enseignants, admin** avec UX claire, perf correcte et tests/doc à jour.

## Périmètre
- Mobile-first **uniquement côté étudiant**.
- Tous rôles: admin/teacher/student.
- DoD: **UX + docs + perf + tests**.

## Backlog (max 7)
1. Étudiant — Vue mobile-first (cartes, filtres simples, résumé rapide).
2. Enseignant — Saisie notes améliorée (feedback, UX, erreurs).
3. Admin — Supervision/validation notes (vue synthèse).
4. Réclamations — UX clarifiée + export admin.
5. Performance — pagination/lazy pour listes lourdes.
6. Tests — unitaires + 1 intégration (saisie → publication).
7. Docs — endpoints + guide utilisateur.

## Plan 2 jours
**Jour 1**
- Audit notes + quick fixes
- Étudiant: UX mobile-first + résumé
- Enseignant: saisie notes UX + feedback
- Tests unitaires (front)

**Jour 2**
- Admin: supervision + publication
- Réclamations: filtres + export
- Perf: pagination/lazy
- Tests intégration + docs

## Definition of Done
- UX validée (mobile-first étudiant)
- Docs à jour
- Perf OK (pagination/lazy)
- Tests OK (unitaires + 1 intégration)
